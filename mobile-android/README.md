# MessenjrAli Mobile (Android)

Android Studio uchun tayyor minimal Kotlin loyiha.

## Ochish

1. Android Studio -> **Open**  
2. Shu papkani tanlang: `mobile-android`
3. AGP/Gradle sync tugashini kuting

## Ishga tushirish

1. Emulator yoki telefon ulang
2. **Run 'app'**

## Eslatma

- Agar Android Studio `Gradle Wrapper` so'rasa, **OK/Generate** qiling.
- Bu skeleton loyiha: shu yerdan feature yozishni boshlaysiz.
